# My Learning Buddy

Free Flutter app and website for children aged 2–6. Requirements: `requirements.md`.

## Workflow (owner's standing instructions)

- After every change: run `flutter analyze` and `flutter test`, commit, then push to the working
  branch **and** to `main`. The Vercel website deploys automatically from `main`
  (`vercel.json` builds it), so every push to `main` updates the live site.
- Keep `requirements.md` up to date with every decision the owner makes.
- When fixing feedback, change only what is needed (e.g. regenerate only the affected voice clips).

## Notes

- Content lives in `assets/content/content.json`; voice clips in `assets/audio/` are generated by
  `tool/generate_audio.py` (see README). `test/speech_test.dart` fails if a clip is missing.
  After making clips, run `tool/check_plurals.py` (needs `pip install pocketsphinx`) so no clip sounds plural.
- The website must make no requests to other servers: build with `--no-web-resources-cdn`; the
  emoji font is served from `web/fonts/`.
